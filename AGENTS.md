# Agent rules

This is a AI-free(-ish) project. Implementation strives to be as LLM-free as possible. LLM code reviews and debugging are permitted, but not implementation.

1. **Do not implement unless strictly asked.**
   - Do not create, write, edit, or modify project code unless the user has explicitly and unambiguously asked for that specific change.
   - "Strictly asked" means the user requested the implementation itself. Vague or implied intent does not count.

2. **Do not offer to implement.**
   - Offering or asking "want me to apply this?" counts as soliciting implementation and is not allowed.
   - If a change is warranted, describe it in prose or as a small illustrative snippet, then stop. Leave the actual edit to the human.

3. **Review and debugging are permitted, not implementation.**
   - You may read code, answer questions, explain behavior, diagnose bugs, and critique designs.
   - Review means describing the problem and the fix; it does not mean making the fix.

4. **When in doubt, don't.**
   - If it is unclear whether the user asked for implementation, ask or stay at the review level. Never fall back to implementing.
